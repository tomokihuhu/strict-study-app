# Strict Study App

日々の学習時間を記録し、モチベーションを維持するためのストイックな学習管理アプリケーションです。
インターンシップへの応募用ポートフォリオとして、フロントエンドからバックエンド、データベース構築まで一貫して個人で開発しました。

## 🎯 アプリの目的
「無駄を省き、学習に集中する」ことをコンセプトに、ダークモードを基調としたミニマルなUIを採用しました。
毎日の学習時間や1週間の合計時間を可視化することで、継続的な学習習慣の定着をサポートします。

## 🛠 使用技術

**フロントエンド**
- Next.js (App Router)
- React
- Tailwind CSS

**バックエンド・認証**
- Next.js (API Routes)
- NextAuth.js (セッションベース認証)

**データベース・ORマッパー**
- MySQL
- TypeORM

**インフラ・その他**
- Cloudinary (プロフィール画像等のストレージ)

## 💡 主な機能

- **ユーザー認証機能**
  - NextAuthを用いた安全なセッション管理
- **学習記録のCRUD機能**
  - 学習科目、時間、成功/失敗、メモの記録（Create）
  - 過去の学習記録のタイムライン表示（Read）
  - 自身の学習記録の削除機能（Delete / 権限チェック実装済み）
- **プロフィール管理機能**
  - アイコン画像のアップロード（Cloudinary連携）
  - ユーザー名、自己紹介文の更新
- **学習時間の集計と可視化**
  - 今日の合計学習時間、今週の合計学習時間の自動計算
